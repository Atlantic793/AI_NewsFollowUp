# headline-chaser

采集各家大模型官网的价目、公开榜、热榜和官方动态，洗成表，并和上一份做差分。

页面包括首页、四栏数据、定制追踪、采集和简报。抓哪些地址、怎样留原文，见 [docs/数据采集与处理.md](docs/数据采集与处理.md)。

- 首页查看今日重点变化、最近成功时间和异常来源，点变化可进入对应栏目核对。
- 价目表支持地域、上下文、缓存、档位、计价项和单位筛选，以及人民币／官网原币种切换。价格按相同计价项、单位和币种分组排序。
- 在价目表、排名和热榜直接关注条目，也可在定制追踪中搜索已有名称；未命中时显示原因。
- 点表格字段，在原文面板切换核对价格、日期或分数。新采集会记录规则抽取、模型补抽、模型补充和概括方式；旧数据标为未记录。
- 采集页显示每个来源最后成功时间和耗时，可只查看异常，或只重试已启用来源中的暂时网络失败项。
- 栏目里的“生成本地简报”开关控制采集后生成当天 Markdown，可在简报页查看、复制和下载。

## 启动

```powershell
conda env create -f environment.yml
conda activate headline-chaser
npm ci
npm run dev
```

浏览器打开 Vite 提示的地址。接口在 `http://127.0.0.1:4177`。

数据集写在本机应用数据目录的 `headline.sqlite`，不进仓库。
