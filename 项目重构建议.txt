项目名称：headline-chaser
设计日期：2026-11-08
抓什么、怎么洗、怎么差分，见 docs/数据采集与处理.md。
这一版只保留现有工作台的视觉风格：白底、细线、黑色主按钮、蓝色强调、三栏工作台。信息架构按数据采集大作业重排。更早的栏目讨论以这一份为准。

参考图只说明版式。图里的价格、名次、日期都是占位，不是采集结果。

================================================================================
页面一共四张
================================================================================

1. 首页 /
2. 数据页 /columns/热榜 | 价目 | 排名 | 动态
3. 定制 /watch
4. 采集 /collect

数据页右侧的「原文」不是单独一页。四个栏目共用这一张数据页，只换中间的表。

不做的页面：一句话新建主题、综合排名、用量排名、向量问答。

================================================================================
1. 首页
================================================================================

顶栏：返回用不到。左上保留三个圆点。中间是 headline-chaser。右上两个入口：定制、采集。
标题下只有一行：今日快照，加上日期。没有搜索框。

四张卡片，始终是全表的最近一份，不按个人名单缩小。

热榜
- 三枚来源开关：GitHub、Hugging Face、Kaggle。关掉的来源不出现在这张卡里。
- 每条：名次或新出现标记、标题、来源、抓取时间。
- 点卡片进入数据页的热榜。

价目
- 七家官网：OpenAI、Anthropic、Google、DeepSeek、月之暗面、阿里云通义、智谱。
- 每家能看到的是 API 价和官方 coding plan 的最近数字。
- 角标写今天有几处变化。没变化也显示这张卡，只是不推送。
- 点卡片进入数据页的价目。

排名
- 三列：LMArena 文本、SWE-bench Verified、Artificial Analysis。
- 每列写榜首的模型名、名次、分数；升降记在差分里。不合成一个总分。
- 点卡片进入数据页的排名。

厂商动态
- 每条：厂商、标题、日期。第一版全部来自官网。
- 状态页里不正常的组件单独列为「服务异常」。
- 地区政策只出现中国大陆的注册、调用、付款。
- 点卡片进入数据页的动态。

================================================================================
2. 数据页
================================================================================

顶栏沿用现在的工作台：返回首页、栏名、状态（今日几处变化）、立即抓取、推送开关。
推送：热榜每天可推。价目、排名、动态只在有差分时推。关掉推送不影响主页显示。

左栏是这一栏的来源（一页一个），每个来源后面写行数；没抽出、失败、跳过时写状态。
- 热榜：GitHub Trending、Hugging Face 模型趋势、Kaggle 竞赛
- 价目：七家厂商的 11 个价目页（API 价和套餐分开）
- 排名：三张榜
- 动态：七家厂商的 12 个更新日志、新闻和状态页

中栏是清洗后的表，是这一页的主体。上方有搜索框；价目可按 API / 套餐筛，动态可按发布、新闻、状态、事故、中国大陆筛。
- 热榜列：来源、名次、条目（链到条目自己的页面）、热度、简介
- 价目列：厂商、产品、档位、计价项、条件、价格、单位、额度、重置。价目表的每一格单独一行
- 排名列：榜单、名次、模型、机构、分数、票数、榜单日期，照榜上原样
- 动态列：日期、厂商、类型、标题、说明。一行是一次发布、一条新闻或一个组件的状态
选中的来源这一轮没抽出或失败时，中栏顶部写原因，不显示旧数据。

右栏标题是「原文片段」。
- 只显示选中那一行在原始响应里的那一段，加上打开原页面、来源名、抓取时间
- 这一行的数字必须能在片段里找到
- 没选行时只写一句提示，不铺整页原文

================================================================================
3. 定制
================================================================================

顶栏：返回、标题「定制追踪」。
左栏：勾过的模型和官方订阅，底部可以添加名字。
右栏不是全表。只列出这些名字今天的变化，分成价目、排名、厂商动态三组。
没有变化就写「今天没有新变化」，并给一个回到首页全表的入口。
每条变化可以打开数据页里对应的那一行原文。

首页不被这份名单过滤。

================================================================================
4. 采集
================================================================================

顶栏：返回、标题「采集」、入库 / 没抽出 / 跳过 / 失败的数量、按钮「再跑一轮」。

左栏按栏目过滤：全部、价目表、排名、热榜、厂商动态。下面列出不抓的页面和原因。
中栏每一行是一个具体页面，不是厂商首页：来源、抓取（HTTP 状态 · 大小）、抽取条数、清洗后条数、丢弃条数、入库行数、变化处数、结果、时间。
右栏是这一页最近一次抓取：
- 登记地址和实际请求的地址
- 抓取、抽取、清洗、入库四步各一句
- 失败或跳过的原因（robots 不允许、403 不绕过、没配凭据等）
- 丢弃原因按条数列出，展开可看被丢掉的原文样例
- 只跑这一页、停用 / 启用、看原始响应、看入库的行

开放平台首页和要登录的控制台不出现在这张表里。
大模型厂商官方信息源.md 里第一版没抓的厂商，不进这张运行表。

================================================================================
用户怎么走
================================================================================

打开首页，看四张最近的卡。
想核对数字，点进数据页，左边选厂商或榜，中间看表，右边看原文。
只关心自己在用的模型，去定制，看这些名字有没有变化。
想知道今天抓没抓到，去采集，看成功、失败和 robots。

抓取由「立即抓取」或「再跑一轮」触发。改源清单之后要先在采集页看到新的一行，再跑。
================================================================================
仍沿用的采集规则
================================================================================

- 价目只来自七家官网的 API 定价页和官方 coding plan 页。
- 排名只转录三张公开榜。
- 厂商动态的结论来自官网原句。第一版只抓官网，社交讨论没有进队列；以后加进来时必须标「尚无官网依据」，有了官网原句之后并进同一条。
- 地区政策只在同一句里同时写到中国大陆和注册、调用、付款时才标出。
- 原始响应整份留档。每轮和上一轮做差分，第一轮只建基线。
- 页面里抽不出这一栏要的行，记「没抽出」并清空旧行，不拿页面上别的文字凑数。
- 不抓 OpenRouter 目录，不自己打综合分。
